# Portfolio

Static React/Vite portfolio designed for GitHub Pages.

## Personalize it

Before deploying, update `src/content.js` with your preferred name, email address, location, and real project entries. Project cards are deliberately empty until you add authentic work.

## Run locally

```powershell
npm install
npm run dev
```

## Publish on GitHub Pages

1. Create an empty GitHub repository.
2. Push this folder to its `main` branch.
3. Open the repository’s **Settings → Pages**, then choose **GitHub Actions** as the publishing source.
4. Pushes to `main` will build and publish the site automatically.
